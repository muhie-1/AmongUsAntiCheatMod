## Among Us Anti Cheat v0.3.0 — Experimental

### New protections

- Host guard rejects known sabotage-start requests during meetings and exile,
  including reactor, oxygen, lights, communications, seismic, helicopter, and
  mushroom mixup. Recognized repair operations still pass.
- Guests receive local warnings for new sabotage activity during meetings.
  These warnings cannot reliably identify the attacker or enforce host state.
- Movement monitoring and its optional host-only kicking remain available.

### Role knowledge limitation

A player silently reading impostor roles cannot be reliably detected by this
local mod. Correct deductions and leaving the game are not treated as proof
of cheating. No hidden roles are revealed by these features.

### Install or update

Close Among Us and extract your edition's ZIP into the game folder. Both DLLs
belong in `BepInEx/plugins/AntiCheat/`; replace both when updating. A compatible
BepInEx 6 Unity IL2CPP loader is required separately. Launch normally and test
in a private lobby before using host enforcement.

### Configuration

New defaults in `BepInEx/config/local.amongus.anticheat.cfg`:

```ini
[Sabotage]
MonitorDuringMeetings = true
BlockDuringMeetingsAsHost = true
```

Disable meeting sabotage blocking for custom rules that intentionally allow
it. `KickOnDetection` applies only to repeated movement detections, never to
claimed sabotage senders.

### Validation and limits

- 513 automated core checks pass, including repair exemptions and meeting transitions.
- Builds against Microsoft Store and Steam references pass without warnings.
- Unity hook behavior, meeting/exile transitions, overlay, and enforcement still
  require private-game runtime verification. Mark this as a prerelease.
- Doors, unknown/custom operations, and other RPC/state-injection paths are not
  covered by the new rule. Network timing can cause missed or misleading alerts.
- A 1.5-second meeting grace period reduces guest state warnings caused by
  delayed updates; attacks within that window can be missed. Existing active
  sabotages are not labeled new attacks. Warnings never establish who cheated.
